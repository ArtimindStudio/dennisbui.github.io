# Hand-over: AI Creative Designer (JOB-SAAS-001)

## 1. Project Context
- **Job Title**: AI Creative Designer (Ecommerce / SaaS Ad Variations)
- **Airtable ID**: JOB-SAAS-001
- **Client Goal**: Take existing ad layouts and generate 10–20 high-quality visual variations (backgrounds, lifestyles, environments) while keeping branding, text, and UI elements 100% consistent.
- **Target Aesthetic**: Clean, modern, professional, ultra-realistic. Inspired by **Stripe, Linear, and Shopify.**

## 2. Established Branding DNA: "Elite Minimalist"
To win this bid, all generated assets must strictly adhere to this "Big Brand" logic:
- **Color Palette**: 
    - **Primary**: #635BFF (Stripe Blue) - Vibrant but professional.
    - **Secondary**: #5850EC (Linear Indigo) - Used for depth and gradients.
    - **Backgrounds**: Deep Navy-Slate (#0F172A) for dark mode; Soft Off-White (#F8FAFC) for light mode.
- **Typography**: Inter or Manrope. Medium weight (500) for headlines, Regular (400) for body. Increased letter-spacing (2-5%) for a premium "airy" feel.
- **Negative Space**: Aggressive use of padding. Every element must have significant "room to breathe."
- **Lighting**: Soft-box studio quality with realistic subsurface scattering. No "plastic" AI textures.

## 3. Technical Workflow: Google AI-Native Engine
- **Google Antigravity**: Used for "Brand DNA Mapping." Locks the UI/text overlay coordinates so they don't drift during variation generation.
- **Google Nano Banana 2**: The primary 4K photorealistic rendering engine. Emphasize "Invisible AI" (PBR lighting, focal depth, grain).
- **Stich (Variation Logic)**: The process of swapping environmental "DNA" while maintaining the "UI Anchor."

## 4. Key Prompts for Asset Creation
- **The SaaS Dashboard**: 4K wide-angle of a glassmorphic UI floating in a premium minimalist office setup.
- **The Shopify Product**: Ultra-realistic skincare/beverage staging with a clean "Analytics/Add to Cart" UI overlay.
- **The Stripe Payment**: Minimalist checkout flow with high-contrast geometric blue/navy blocks.

## 5. Strategic Positioning
We are pitching the user not as a "prompt dabbler," but as a **Creative Automation Architect.** We don't just provide the variations; we provide the **system** that generates them at scale with perfect brand consistency.
